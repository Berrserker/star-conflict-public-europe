SC Launcher 0.7.1
=================

Назначение
Подключает установленную Steam-версию Star Conflict к серверу
Star Conflict Europe - Unofficial Server (57.131.200.242:3801) и ставит клиентские
файлы под сервер (экран входа, рецепты, магазин, лимиты).
Лаунчер — один exe, launcher-config.ini рядом с ним не обязателен.

Оконный режим
Запустите SC-Launcher.exe без параметров. При открытии он проверяет пресет
сервера и файлы модов и ставит недостающие или изменившиеся. В окне есть:
- «Играть»: ещё одна проверка и запуск игры (передаётся Steam App ID 212070);
  если игры нет, кнопка становится «Установить игру» (steam://install/212070);
- «Проверить обновления»: та же проверка с сообщением о результате;
- сайт, Discord, новости (из news.json сервера);
- флаги России и Великобритании: язык лаунчера и игры;
- «Настройка»: установка и удаление модификации, строка для запуска из Steam.

Запуск через Steam (рекомендуется)
1. Положите SC-Launcher.exe в обычную папку (не в папку игры).
2. В лаунчере: «Настройка» -> «Запуск через Steam» -> «Копировать». В буфер
   попадёт строка вида  "C:\Games\SC-Launcher.exe" %command%
3. Вставьте её в Steam: Star Conflict -> Свойства -> Общие -> Параметры запуска.
Каждый запуск из Steam проходит без окна: проверка пресета и модов, затем игра
со всеми параметрами Steam; лаунчер ждёт её закрытия и возвращает код выхода.
Если проверка не удалась, ошибка пишется в launcher.log, а игра всё равно
запускается. Встроенный localhost-сервер на время запуска отключается
(win64\launch_server_and_db.bat подменяется заглушкой и потом возвращается,
параметр -launchLocalServer убирается). SuppressLocalServer=false оставляет его.

Моды
Манифест https://star-conflict-eu-server.mak17.workers.dev/sc-mods/manifest.txt
встроен (ModManifestUrl= в launcher-config.ini его переопределяет, пустое
значение отключает моды). Формат UTF-8, поля через табуляцию, только HTTPS:

SCMOD1
относительный/путь<TAB>SHA-256<TAB>https://адрес/файла

Каждый путь и хеш проверяются. При первой замене файла игры оригинал
сохраняется в
%LOCALAPPDATA%\Targem\StarConflict\community-server-preset\mod-originals
а новые файлы записываются в mod-added.txt, поэтому удаление возвращает сток.

Новости
Встроенная лента https://star-conflict-eu-server.mak17.workers.dev/news.json
(NewsFeedUrl= её переопределяет). Формат: {"version":2,"items":[{"id",
"date":"ГГГГ-ММ-ДД","url","ru":{"title","summary","url"},"en":{...}}]};
до 10 записей, 256 КБ, ссылки только HTTPS; последняя копия кэшируется.

Linux (Proton)
Под Proton лаунчер не видит сеть (ошибка разрешения имён в Wine-Mono).
Вместо него нативный скрипт, потом игра запускается из Steam как обычно:
  curl -fsSL https://star-conflict-eu-server.mak17.workers.dev/linux/sc-mods.sh | bash
Откат: та же команда с  bash -s -- --restore

Безопасность
- Логины, пароли и токены не запрашиваются и не сохраняются.
- Исходные файлы игры в комплект не входят.
- Exe не подписан: Windows может показать «Неизвестный издатель».

Удаление
1. Уберите строку лаунчера из параметров запуска Steam.
2. Запустите SC-Launcher.exe, «Настройка» -> «Удалить модификацию». Файлы игры
   вернутся к стоку, на экран входа вернутся пункты localhost и server.

Неофициальная утилита сообщества, не связана с Gaijin или StarGem.
